# Java Core Interview Reviewer

A deep-dive preparation guide for **Senior Java Engineers** and **Technical Leads** targeting FAANG-level and enterprise interviews.

## Audience

- 5–15 years of Java experience
- Already fluent in syntax and day-to-day APIs
- Needs **why**, internals, trade-offs, and production judgment
- Preparing for senior IC and tech-lead interview loops

## What You Get

| Layer | Chapters | Outcome |
|-------|----------|---------|
| Language & APIs | 01–05, 08–10 | Speak at Principal depth on core Java |
| Runtime | 06–07 | Debug concurrency and JVM issues under pressure |
| Drill | 11 | Timed Q&A with model answers |
| Lead track | 12–14 | Ownership, Spring Boot, system design |

## How to Study

1. Skim [SUMMARY.md](SUMMARY.md) and score yourself honestly per chapter.
2. Study weak chapters end-to-end using the fixed chapter template.
3. Teach each topic out loud in 5 minutes (interview simulation).
4. Drill [11-Interview-Questions.md](11-Interview-Questions.md) with a timer.
5. For lead roles, rehearse stories from [12-Technical-Lead.md](12-Technical-Lead.md) and designs from [14-System-Design.md](14-System-Design.md).

## Chapter Template (Every File)

Each chapter uses the same structure so you can scan and compare:

1. Introduction  
2. Definition  
3. Internal Working  
4. Why it exists  
5. Advantages  
6. Disadvantages  
7. Time Complexity (if applicable)  
8. Memory Considerations  
9. Code Examples  
10. Common Interview Questions  
11. Senior Engineer Notes  
12. Technical Lead Perspective  
13. Best Practices  
14. Common Mistakes  
15. Summary  
16. Cheat Sheet  
17. Exercises with Answers

## Conventions

- **Must know** — expected in senior rounds  
- **Deep dive** — differentiates strong seniors / principals  
- **Trap** — common wrong answer interviewers probe  
- **Lead angle** — how a tech lead frames the same topic
